# Hardik Pajiala — portfolio

Live at **https://pajiala99.github.io**

A single-file interactive portfolio (`index.html`, no build step): projects with full write-ups,
a skills chart that counts evidence rather than self-ratings, a timeline, and a guide character
who answers questions from my record. Themed as a fan homage to Hunter × Hunter.

Projects featured: FoodBridge, Cricket Win-Probability Lakehouse, PRAMAAN (AI agent),
Indian Sign Language Recognition, E-Commerce Data Lake Pipeline, Malaria Cell Classification,
Lost & Found System.

Run locally: open `index.html` in a browser, or `python3 -m http.server` in this folder.
